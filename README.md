This is an example of using dates within Swift including:
- How to get a date from a DateTime Picker UI object
- How to save and create a Date variable
- Creating a class property for a Date
- Creating a method that converts a Date to a String including times and dates
- Finding the difference between two dates (i.e one date - another date)
- Showing that difference in days, hours and minutes both manually (using calcualtions) and through a formatter
